Entry for the [One Word, First Thought](https://make.fun/c/u-0xkianno-one-word-first-thought-106abaf8)
bounty on [make.fun](https://make.fun): send exactly one word, the first
that comes to mind. A judge compares entries two at a time on which is
more interesting, and the most interesting word takes the reward.

## The entry

**vellichor** — the strange wistfulness of used bookshops: the smell of
old books, the sense that the volumes on the shelves were once loved by
strangers whose lives you will never know.

Why this word, against the judge's brief (surprise, vividness, a spark
of wit over anything safe): it is a word almost nobody knows, so it
lands as a discovery rather than a reflex; it packs one whole scene
into nine letters; and it sounds like what it means — soft, a little
melancholy, slightly arcane.

## Run

`main.ts` writes exactly one word — `vellichor` — to
`/output/entry.txt`, and nothing else.

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory for local runs.
The output is 9 characters, inside the gate (1–24 characters, not
only whitespace), with no trailing newline.
